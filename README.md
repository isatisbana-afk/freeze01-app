# freeze01-app | K-CORE Independent Payroll Engine

موتور محاسباتی مستقل حقوق و دستمزد عوامل اجرایی و نظارتی کارگاه (رده‌های S01 تا S12).

## مشخصات معماری و مالکیت فکری
* **طراح، مجری و ناظر ارشد:** حسین کلانتری
* **وابستگی سازمانی:** عضو اولین هیئت مدیره سرپرستان کارگاه ساختمانی یزد
* **الگوریتم محاسباتی:** خطی مستقیم (حذف کامل فرمول غیرخطی جذری)
* **معماری:** ایزوله و مستقل (Loose Coupling) جهت اتصال به هسته اصلی (`core-logic-engine`)

## فرمول ریاضی محاسبات ($S_i$)
$$S_i = B_i \times (n_1 \times n_2 \times n_3 \times n_4 \times n_5 \times n_6 \times n_7 \times n_8) \times n_P$$

* **$S_i$:** خالص دریافتی ماهانه
* **$B_i$:** پایه حقوق مصوب (به‌روزرسانی سالانه)
* **$n_1 \dots n_8$:** ضرایب ۸گانه محیطی و کارگاهی
* **$n_P$:** ضریب وزن نقش (سطوح S01 تا S12)

## فایل‌های کلیدی شاخه
* `kcore_config.yaml`: پیکربندی امنیتی، متادیتا و مجوزهای ویرایش مولف
* `payroll_schema.json`: ساختار استاندارد داده‌های ورودی و خروجی
* `payroll_engine.js`: موتور اجرای محاسبات خطی
