# 🏗️ سامانه محاسبه حقوق و صورت‌وضعیت K-CORE / M-100

این سامانه یک ابزار وب‌بنیاد و سبک برای محاسبه دقیق حقوق پرداختی پرسنل، اضافه کاری مستقیم و صورت‌وضعیت قابل پرداخت به پیمانکار بر اساس مدل ساختاریافته **K-CORE** و آیین‌نامه‌های **M-100** است.

---

## 📐 فرمول اصلی محاسبات

$$S_i = B_i \times \prod_{j=1}^{8} n_j = B_i \times (n_1 \times n_2 \times n_3 \times n_4 \times n_5 \times n_6 \times n_7 \times n_8)$$

- **$B_i$ (حقوق پایه):** حقوق پایه مصوب کارگاه یا قانون کار (ریال)
- **$n_1$ (ضریب رده شغلی):** ضریب اختصاصی نقش‌های S01 تا S12
- **$n_2 \dots n_8$ (ضرایب ۷‌گانه محیطی):** ضرایب شرایط اقلیمی، دوری از مرکز، خطرات کارگاه، شیفت کاری، حساسیت پروژه، زمان‌بندی و تجربه

---

## 📊 جدول ضرایب رده شغلی ($n_1$)

| کد نقش | عنوان شغلی | ضریب ($n_1$) |
| :---: | :--- | :---: |
| **S01** | نیروی اجرایی پایه | 1.00 |
| **S02** | نیروی اجرایی | 1.05 |
| **S03** | نیروی اجرایی ارشد | 1.10 |
| **S04** | سرپرست | 1.18 |
| **S05** | سرپرست کارگاه | 1.25 |
| **S06** | مدیر بخش | 1.35 |
| **S07** | مهندس ناظر | 1.45 |
| **S08** | مهندس ناظر ارشد | 1.60 |
| **S09** | مدیر فنی / کارشناس ارشد | 1.75 |
| **S10** | مدیر پروژه | 1.90 |
| **S11** | مدیر ارشد پروژه | 2.10 |
| **S12** | مدیر پروژه ویژه | 2.30 |

---

## ⏰ محاسبات اضافه کاری

1. **نرخ ساعتی پایه:** $\text{Hourly Rate} = \frac{S_i}{220}$
2. **اضافه کاری پرداختی به نیروی کار:** $\text{Overtime}_{\text{Worker}} = \text{Hours} \times \text{Hourly Rate} \times 1.40$
3. **اضافه کاری صورت وضعیت پیمانکار:** $\text{Overtime}_{\text{Contractor}} = \text{Hours} \times \text{Hourly Rate} \times 1.66$
