# freeze01-app | فرانت‌اند و رابط کاربری وب Freeze-01

این مخزن شامل اپلیکیشن وب (Web App / PWA) برای محاسبه هوشمند حقوق و وضعیت هشدارهای پروژه Freeze-01 است.

## 📂 ساختار فایل‌ها
* `index.html`: رابط کاربری وب، فرم ورودی اطلاعات و نمایش رنگی وضعیت هشدارها.
* `payroll_engine.js`: موتور کلاینت برای اجرای محاسبات هم‌زمان در مرورگر.
* `styles.css`: استایل‌ها و رنگ‌بندی هشدارهای ۵‌گانه.
* `sw.js`: سرویس ورکر برای پشتیبانی آفلاین (PWA).

## 🚀 نحوه اجرا
این برنامه مستقیماً از طریق GitHub Pages یا اجرا در مرورگر بدون نیاز به سرور جانبی قابل بهره‌برداری است.
